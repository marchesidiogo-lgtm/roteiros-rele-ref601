# Roteiros práticos: relé de proteção ABB REF601/REJ601 via IHM

Conjunto de quatro roteiros de laboratório para aprender a operar e configurar o relé digital de proteção ABB REF601/REJ601 (variante com TCs convencionais) exclusivamente pela interface homem-máquina (IHM) local. Produzidos na disciplina de Projetos Aplicados 3, do curso de Engenharia Elétrica do IFES, Campus Guarapari.

Os valores de ajuste usados nos roteiros são didáticos. Não representam estudo de seletividade nem devem ser usados em instalações reais.
